# 文章评论功能设计

## 概述
为 SK 小站的文章增加评论功能。访客可对文章发表评论，3 分钟内可删除自己的评论，超时后删除按钮消失。后台管理员可以删除任意评论。

## 数据层

### localStorage 键
- 新增 `sk_comments`：存储所有评论
- 新增 `sk_visitor_id`：存储当前浏览器的访客 ID

### 评论数据结构
```js
{
  id: "1712345678901",        // 时间戳，唯一标识
  articleId: "1712345678000", // 所属文章 ID
  nickname: "小明",            // 评论者昵称
  content: "写得好！",         // 评论内容（纯文本，防 XSS）
  timestamp: 1712345678901,   // 评论时间戳
  visitorId: "a1b2c3d4"      // 访客 ID，用于 3 分钟内删除
}
```

## 前端 — 评论展示

### 访客 ID 初始化
- `index.js` 启动时检查 `localStorage.getItem('sk_visitor_id')`
- 不存在则生成一个随机 UUID 并存入

### 文章弹窗评论区
- 弹窗底部，用分隔线与文章内容隔开
- 评论按时间正序排列
- 每条评论显示：昵称、内容、时间
- 若 `visitorId === 当前访客ID` 且 `Date.now() - timestamp < 180000ms` → 显示删除按钮
- 删除按钮为红色小字，位于评论右下角，点击后确认并删除

### 评论表单
- 昵称输入框 + 内容输入框 + 提交按钮
- 提交时校验：昵称不能为空，内容不能为空
- 提交后写入 `sk_comments`，立即刷新评论列表
- 首次加载时如果 `localStorage` 中有历史昵称则可自动填充

## 后台 — 评论管理

### admin.html 新增"评论管理"面板
- 按文章分组显示所有评论
- 每条评论展示：昵称、内容、时间、所属文章标题
- 每条评论有"删除"按钮，点击即删，无时间限制
- 文章删除时连带删除其所有评论

## 样式

### 评论区样式（index.css）
- 评论区域与文章内容用浅色分隔线隔开
- 每个评论为一个卡片块，有轻微背景色和圆角
- 评论时间用小号灰色字体
- 删除按钮为红色，右侧悬浮或右下角

### 后台评论管理样式（admin.css）
- 评论以列表或表格形式展示
- 每个评论项有清晰的分组和边框

## 文件变更清单

| 文件 | 变更 |
|------|------|
| `index.js` | 新增 visitorId 初始化、评论 CRUD、评论渲染、3 分钟删除逻辑 |
| `index.css` | 新增评论区/评论卡片/删除按钮样式 |
| `index.html` | 无变更（评论内容动态渲染到弹窗内） |
| `admin/admin.js` | 新增评论管理面板、评论分组展示、删除功能 |
| `admin/admin.css` | 新增评论管理样式 |
| `admin/admin.html` | 新增评论管理的 HTML 面板结构 |

## 边界情况
- 无评论时显示"暂无评论"
- 删除文章时同时清理其所有评论
- 输入的昵称和内容做 XSS 转义（沿用已有的 `escapeHtml`）
- 提交内容不能为空，为空时提示
- 多个 tab 同时打开时，评论列表在切换回学习区时自动刷新
